# 仮説エピソード

`templates/hypothesis-episode.md` を使用します。検証予定と実際の検証結果を
明確に分けて記述します。

仮説エピソードは、一度の検証で仮説を完全に証明するための文書ではなく、
境界を明示した小さな学習記録です。少人数へのインタビュー、資料調査、
専門家レビュー、小規模な試行も利用できます。観測できた範囲に合わせて
結論を限定し、対象の選び方、実施規模、未確認事項を記録してください。

GenAIは調査可能性の確認、資料探索、質問案の作成、提供された記録の整理に
利用できます。ただし、GenAIの回答自体は証拠ではありません。実際に確認した
資料または実施したインタビューを根拠となるリポジトリノードとして保存し、
型付きrelationで参照してください。架空の参加者や予測した回答を検証結果として
扱ってはいけません。

実務経験から形成された仮説には`practitioner_experience`を付けます。このBasisと
`not_tested`は両立します。経験知として提案できることと、このRepositoryで
独立検証したことを分け、どちらかを理由にもう一方を推測しません。
