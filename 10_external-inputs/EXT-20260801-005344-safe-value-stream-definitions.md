# SAFeにおけるDVSとOVS

## 位置づけ

Scaled Agile, Inc.が公開するSAFeの公式ページを、Development Value Stream
（DVS）とOperational Value Stream（OVS）の用語参照として保存する。

本ノードは用語の外部参照であり、SAFe全体を今回の分析または登壇へ採用する
判断や、個別のValue Stream分類が正しいことを示すEvidenceではない。

## 外部ページが説明していること

SAFeは二種類のValue Streamを区別している。

- Development Value Stream（DVS）:
  顧客価値を届けるデジタル対応SolutionへBusiness Hypothesisを変換するために
  必要な一連の活動。Operational Value Streamが使用するProductまたはSolutionを
  開発し、支援する活動を扱う。
- Operational Value Stream（OVS）:
  顧客へProductまたはServiceを届けるために必要な一連の活動。

SAFeのCustomer Centricityに関する公式説明では、組織内部のCustomerも、DVSが
開発したProductまたはSolutionを、一つ以上のOVSで利用する場合があるとしている。
