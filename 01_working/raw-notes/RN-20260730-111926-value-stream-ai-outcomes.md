# メモ

Value Stream上のタスクの課題に応じて、
AIでどのような効果を出したいかを考える。

- Process Timeが長い
  - AIによるSpeed Upを狙う
- Lead Timeが長い
  - なぜLead Timeが長いのか、別途深掘りする必要がある
- 手戻り率が高い
  - 元の意思決定品質に問題がある
  - なぜ意思決定品質が悪いのかを考える
  - そのうえで、意思決定品質を向上させる施策を考える

# 仮説の状態

これは現時点では、かなり確度の低い柔らかな仮説である。

特に、Value Stream上で観測された課題と、
AIで狙うOutcomeをこのように対応づけてよいかは検証できていない。

後でAssistAなどを使い、
本当にこの対応関係が成立するのか、
見落としている原因や別の解釈がないかを反証的に確認する。
