# Raw Note

低負荷な原資料を置く場所です。`templates/raw-note.md` を使ってください。

本文は未整理の短文、箇条書き、会話の貼り付けでも構いません。frontmatterの
provenanceだけは記録し、後から派生物を作っても元ファイルを残します。

ここでいうRawは、文章が粗いことや、人間が直接執筆したことを意味しません。
人間がAssistAやCodexとの対話を通じて考えを練り、その時点の内容をGenAIへ
整理・記録させた文書もRaw Noteとして扱えます。

Raw Noteであるかは文章の完成度ではなく、会話や形成途中の思考を原資料として
保存する役割で判断します。既存の複数Sourceを後から横断し、新しい観察、解釈、
主張を生成する場合は、Raw Noteではなく `02_analysis/` の派生ノードとして
記録します。
